# CodeAlpha Project 2: Stock Portfolio Tracker

A console-based tracker that calculates the total value of a portfolio using manually defined sample stock prices.

## Features
- Displays available stock symbols and sample prices.
- Accepts multiple stock entries and quantities.
- Combines repeated entries for the same symbol.
- Validates stock symbols and quantities.
- Calculates each holding's value and total investment.
- Optionally exports the portfolio to `portfolio.csv`.

## Requirements
- Python 3.8 or later
- No third-party packages required

## Run
```bash
python stock_portfolio.py
```

## Concepts used
Dictionaries, functions, loops, input validation, arithmetic, `pathlib`, and CSV file handling.

## Important
Prices are hardcoded sample values for practice, not real-time or investment advice.
